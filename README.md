# Анализ рынка видеоигр 2000–2013: предобработка данных

Учебный исследовательский проект команды **«Секреты Тёмнолесья»** — анализ развития  
индустрии видеоигр с 2000 по 2013 год. Цель — подготовить корректный срез данных  
для аналитической статьи: отобрать игры нужного периода, категоризовать их по оценкам  
критиков и пользователей, выделить ключевые платформы эпохи.

## Задачи исследования

1. **Знакомство с данными** — загрузить `new_games.csv`, изучить структуру, типы данных и объём выборки.
2. **Предобработка данных** — обработать пропуски, привести типы данных, найти и устранить неявные и явные дубликаты.
3. **Формирование среза** — отобрать игры, выпущенные в период **с 2000 по 2013 год включительно**.
4. **Категоризация оценок** — разбить игры на категории по оценкам критиков и пользователей:
   - **высокая** — `[80; 100]` / `[8; 10]` (включая правые границы);
   - **средняя** — `[30; 80)` / `[3; 8)`;
   - **низкая** — `[0; 30)` / `[0; 3)`.
5. **Топ-7 платформ** — определить платформы-лидеры по количеству игр за 2000–2013 гг.

## Данные

Источник — датасет `new_games.csv` с данными о продажах игр разных жанров и платформ,  
а также пользовательских и экспертных оценках.

| Поле | Описание |
|---|---|
| `name` | Название игры |
| `platform` | Игровая платформа |
| `year_of_release` | Год выпуска игры |
| `genre` | Жанр игры |
| `na_sales` | Продажи в Северной Америке (млн копий) |
| `eu_sales` | Продажи в Европе (млн копий) |
| `jp_sales` | Продажи в Японии (млн копий) |
| `other_sales` | Продажи в других странах (млн копий) |
| `critic_score` | Оценка критиков (0–100) |
| `user_score` | Оценка пользователей (0–10) |
| `rating` | Рейтинг ESRB (E, T, M, AO, RP, E10+, EC, K-A) |
